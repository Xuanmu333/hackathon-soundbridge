# SoundBridge 安全主线概念影片

新版：`SoundBridge_Safety_Humanity_150s.mp4`。150 秒、1920 × 1080、30 fps，中文合成旁白、画内中英字幕、原创合成配乐。旧版影片及旧版字幕保留供对比；当前 Remotion 源码对应本安全版。

## 已确认的叙事方向

以出行中的环境安全为主线，以自主生活与平等相处体现人文关怀。主故事是独自出门、车铃提示、观察确认、自主让行、与朋友相聚；不以救助、怜悯或焦虑作为情绪来源。

移除交谈模式和泛化的人声提醒。并不据此假设所有聋人和重听人士采用同一种沟通方式。居家门铃保留为另一日常场景。

## 体验与技术边界

- 流程：环境声音 → 短时频谱特征 → 本地模型 → 置信度与时序判断 → 触觉、图标和文字 → 用户观察并决定行动。
- 车铃、鸣笛采用三次短振；门铃采用两组双击。节奏是待用户测试的概念设计，不是已验证标准。
- 来向是相对手表的辅助线索，需要兼容阵列、校准及实际佩戴测试。不可靠时展示“方向不确定”，不绘制方向扇区。
- 暂停、低电量、感知不可用是新增的拟议状态设计。暂停/故障显示无法提供提醒，不将无提示等同于安全。
- 文字、图标与振动共同表达事件，不能只凭颜色判断。
- 本地处理、默认不保留原始录音、可选的类别及时间历史，均为待落地的隐私目标。
- 项目是概念展示。未验证硬件、识别准确率、漏报率、误报率、来向精度、时延或续航；片中没有实测性能数字或避险保证。

## 素材

步道及朋友相聚画面是 AI 生成的虚构人物关键帧，经过帧驱动推拉动画呈现，不是实地用户测试或实拍产品证明。三个画面使用同一人物参考；完整提示词记录于 `素材提示词.md`。居家片段沿用项目原有视频。手表交互与技术流程通过 Remotion 动画演示。

## 工程与交付

- 当前工程：`../soundbridge-film/`，预览运行 `npm run dev`，完整时间线为 `SoundBridge-Film`。
- 本版旁白：`public/voice-safety/`，与旧版语音目录分离，避免误用缓存。
- 本版字幕：`SoundBridge_Safety_中英字幕.srt`；`captions.safety.zh.json`。
- 生成脚本：`scripts/prepare_audio.py`；声音为 `zh-CN-XiaoxiaoNeural`。
- 原创配乐：`scripts/make_score.py`；渲染使用本机 Chrome。
- 原英文网页版 PPT 与原 60 秒视频保留，本次修改范围为 150 秒影片及对应工程。
