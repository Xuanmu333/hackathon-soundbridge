红黑产品配色

按新的参考要求，产品采用红色金属表壳、暗红色表带和黑色玻璃表盘；环境采用炭黑、灰色控制卡片与局部红色反射，绿色仅用于状态灯和少量滑杆点缀，主按钮、选中卡片和流程高亮均使用中性灰白。识别与提醒仍保留文字和图标，不只依靠颜色区分。

材质、布光与构图的再次打磨

参考的核心层级是炭黑环境、灰色操作面板、红色产品与近场红色反光。产品始终是画面主角。对照官方手表产品摄影后，针对本模型重新构建了圆润表壳倒角、曲面玻璃、精细表冠、哑光细纹表带与边缘缝线。宽大均匀的高光改为可控摄影棚反射光板，地面倒影加入距离衰减与柔化，软阴影帮助建立落地关系。

直接借鉴的是材质分工、曲面明暗和产品主次关系；需要改造的是适配圆形 SoundBridge 手表的几何、布光与交互视角；不复制 Apple 的品牌、表盘或模型；无法从参考照片确认其真实灯位、镜头参数或渲染方式，因此这里的参数由本项目自行建立并检查。参考：Apple 官方产品图片。这些是视觉观察与实施判断，不代表复原其制作工艺。

一条能够看懂的技术链路

  1. 发声：选择车铃、门铃或鸣笛。方位控制改变三维空间中的声源位置。
  2. 传播：有限的波前从声源向外扩散；传播距离与时间经过放大，便于观看。
  3. 接收：波前抵达手表，多处收音点亮起，信号汇入内部电路。
  4. 识别：结构分层展开，呈现短时采样、频谱特征、本地类别识别及确认门控。右侧小面板解释置信度筛选、连续确认和重复抑制。
  5. 提醒：识别结果对应表盘图标、文字和不同振动节奏；触觉部件运动与提醒波纹同步。
  6. 结束：一次提醒结束后停止振动。暂停或故障时，传播、接收、识别和触觉反馈都不再继续。

人文关怀体现在控制权

安全是叙事主线，产品提供环境线索，使用者自主观察和决定。演示保留暂停、低电量、故障、大字、振动强度和方向不确定等状态；通过图标、文字、触觉共同表达，避免仅依赖颜色或声音。没有交谈或语音回应作为核心使用前提。

本地处理与不保存原始录音是拟议产品方案；演示程序本身不调用麦克风、不采集声音，也没有实现真实声学识别。硬件布局是可编辑的概念模型，识别准确率、漏报、误报、来向估计、功耗、振动感受与佩戴体验均需真实设备验证。

交付与使用

播放三维新版视频 · 打开交互控制台（需本地 HTTP 服务）

开发预览：在 soundbridge-film 文件夹运行 npm run lab，打开 http://127.0.0.1:3010/three-lab.html。完整视频与交互版共用三维模型及状态逻辑，便于继续调整。旧版视频保留，方便比较。

三维模型由几何体和程序生成的曲面构成，未使用外部模型或第三方截图。人物画面沿用项目中已生成的虚构人物素材。旁白、字幕及音乐沿用已核对的安全版；三维渲染按固定帧推进，保证画面可重复输出。

技术依据

Remotion ThreeCanvas 支持按帧输出三维画面；Three.js 物理材质 配合本项目生成的摄影棚反射光板、环境贴图与平面反射。使用真实网格、材质、相机、灯光与反射，不把平面 CGI 图片当作可旋转模型。
