# SoundBridge — interactive concept presentation

Twenty English slides, designed for a live concept presentation.

Open dist/index.html directly for offline use, or serve the dist folder:

    python -m http.server 8080 --directory dist

Controls: left/right arrows, Space, Page Up/Down, Home/End, F for fullscreen,
O for the slide overview. Touch screens support horizontal swipes.

The slides include an interactive setup walkthrough, sound selection,
haptic pattern previews, a directional sector, context modes, pause/resume,
and text-size and vibration preferences.

All interactions are concept simulations. This website does not access a
microphone or perform sound recognition. The proposed product runs on the
watch; directional sensing requires appropriate hardware and acoustic
validation. No claim of completed user research is made.

The lifestyle imagery is AI-generated for this presentation. Typography,
white space, and motion take inspiration from premium consumer product
presentations; this is an independent concept, not an Apple product.

Motion respects the reduced-motion preference. A static PDF can be saved
from the help menu. No framework, external font, account, analytics, or
network service is required to use the offline presentation.
