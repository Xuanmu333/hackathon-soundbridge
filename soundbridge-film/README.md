# SoundBridge — Technology with Humanity

A 150-second, 1920×1080, 30 fps concept film with Chinese narration, bilingual subtitles, original synthesized music, animated watch demonstrations, and lifestyle footage from the existing project video.

## Preview

```sh
npm install
npm run dev
```

Select `SoundBridge-Film` for the full timeline. The `Scenes` folder contains each independently editable chapter.

## Render

```sh
npx remotion render src/index.ts SoundBridge-Film ../SoundBridge_Film/SoundBridge_Tech_Humanity_150s.mp4 --codec=h264 --crf=18 --concurrency=4
```

On this Mac, the installed Chrome renderer was used successfully via `--browser-executable='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'`.

## Content and assets

- `src/script.json`: scene timing, Chinese narration, English translations and voice timings.
- `src/scenes/`: the twelve visual chapters.
- `src/visuals.tsx`: watch, signal, subtitle and shared layout components.
- `public/voice/`: generated Chinese voice clips, using `zh-CN-XiaoxiaoNeural`.
- `public/footage/`: reframed extracts of the project's supplied 60-second video.
- `public/score.wav`: original ambient score, generated by `scripts/make_score.py`.
- `scripts/prepare_audio.py`: narration generation and synchronized SRT export. Requires `edge-tts` and `numpy`; FFmpeg and FFprobe must be available.
- `scripts/qa.mjs`: chapter stills for layout inspection.

The film explains a proposed implementation. It does not claim that hardware, sound recognition, acoustic direction estimation, battery performance or user studies have been validated. See `../SoundBridge_Film/制作说明与分镜.md` for the complete storyboard and source references.
